# Towards a Unified View of Sensor Fusion — book sources

*Theory, Methods, and Autonomous Driving Applications*
K. M. Deliparaschos, G. Oliva, T. Charalambous — Springer Nature monograph (SNmono class), delivery 1 December 2026.

This folder is **self-contained**: everything needed to compile the book is here, and nothing in
`companion_repo/` is required for compilation (the generated data files and figures are shipped in
`data/` and `figures/`).

## Layout

| Path | Content |
|---|---|
| `main.tex` | root file (preamble, revision-markup macros, chapter list) |
| `chapters/chNN_<slug>.tex` | one file per chapter, in book order |
| `frontmatter/` | preface, book abstract, acknowledgements (empty Springer placeholders kept: dedication, foreword, ethics, acronyms) |
| `backmatter/` | `solutions.tex` (collects `solutions_chNN.tex`, one per chapter with problems), author biographies, (empty) appendix and glossary |
| `bib/references.bib` | the bibliography (additions of the October 2026 round were merged from `bib/additions_chNN.bib`, kept for traceability) |
| `style/` | `SNmono.cls`, Springer BibTeX styles (`spmpsci.bst` is used), MakeIndex styles |
| `figures/` | static figures (`figures/src/` holds the draw.io sources); `figures/chNN/` holds figures generated by the companion code |
| `data/chNN/` | CSV files read by pgfplots figures (generated by the companion code, shipped here) |
| `docs/` | Springer SNmono instructions, readme and chapter template |
| `scripts/check_chapter.sh` | compiles one chapter (or `all`) in an isolated scratch copy (`build/`) and lists LaTeX errors |
| `docs/REVISION_NOTES_2026-10.md` | what changed in the October 2026 round, chapter by chapter, and the items left for the authors |
| `main.pdf` | the compiled book with the revision markup (regenerate with `make`) |
| `companion_repo/` | GitHub-ready companion repository: `snfusion` Python library, scripts and Jupyter notebooks reproducing every worked example, exercises with solutions, tests |

## Compiling

```bash
latexmk -pdf main
```

or, explicitly,

```bash
pdflatex main && bibtex main && makeindex -s style/svind.ist main && pdflatex main && pdflatex main
```

`make` does the same. On Overleaf, upload the folder (optionally without `companion_repo/`) and set `main.tex` as the main document.

## Revision markup (October 2026 round)

All earlier revision rounds (green/blue/olive/cyan markup of the IEEE Access survey and of the first book draft) have been
**accepted and flattened**: black text is the agreed baseline. In this round

* **blue** = added text (`\added{...}` inline, `\begin{addedblock}...\end{addedblock}` for paragraphs, sections, equations, examples, figures, tables);
* **red** = removed text (`\deleted{...}` inline, struck through; `\begin{deletedblock}...\end{deletedblock}` for paragraphs).

To obtain the clean camera-ready version, set `\revisionmarkupfalse` in `main.tex`: added text turns black and deleted text disappears.
The book outline (chapter and section titles, order) was not changed; new material appears as subsections, worked examples,
end-of-chapter *Problems* (solutions collected at the end of the book) and chapter abstracts.

## Regenerating data and figures (optional)

```bash
cd companion_repo
make install      # pip install -e . (numpy, scipy, matplotlib, pandas)
make examples     # runs every examples/*/ script
make export       # copies outputs into ../data/chNN and ../figures/chNN
```

See `companion_repo/README.md` for the mapping between scripts, notebooks and book examples.
