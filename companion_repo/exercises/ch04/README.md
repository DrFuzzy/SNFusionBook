# Chapter 4 exercises

The complete revised problem statements, with the same numbering as the book, are in `problems.tex` (a LaTeX excerpt using the book preamble). Worked answers are in the book's **Solutions to the Problems**. Analytical and design exercises are intended to be solved by hand or discussed; the following computational scripts have matching generated notebooks.

- `solutions/prob6_miscalibrated_head.py`
- `solutions/prob7_pose_graph_2d.py`
- `solutions/prob9_10_comma2k19.py`

Run a script from this chapter folder, for example `python3 solutions/prob6_miscalibrated_head.py`. Use Python 3.9+ with NumPy, SciPy and Matplotlib (pandas is needed for the public-driving-data example).

The comma2k19 exercise requires the public cache downloaded by the Chapter 4 example downloader. Reference-relative NEES and coverage are diagnostics because the reference uses some of the same GNSS observations.
